# estim-camming

estim-camming controls an output device from tips received on webcam streaming
sites. It shows what is happening on stream through an OBS overlay, and gives
the performer a control panel with an emergency stop.

- The **[User guide](user-guide/index.md)** covers installing, configuring and running it.
- The **[Design documentation](design/index.md)** covers the architecture, the
  plugin interfaces, and how to add support for new sites and devices.
